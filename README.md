## Installation
**1.** Download the `config.jsonc` file of the configuration you want to use.

**2.** Locate the possible directories for fastfetch configuration files with `fastfetch --list-config-paths` in your terminal.

**3.** Place the `config.jsonc` file in one of those directories.

**4.** Specify the configuration file for fastfetch with `fastfetch -c /your/path/to/config.jsonc`.

## Customization
Fastfetch configuration files are easy to customize. You just need to locate the `config.jsonc` file and edit it.

[Options for fastfetch configuration.](https://github.com/fastfetch-cli/fastfetch/wiki/Configuration).
